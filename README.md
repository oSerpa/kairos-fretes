# Kairós Fretes

Landing page da Kairós Fretes, serviço de fretes no DF e entorno.

Site estático feito com HTML, CSS e JavaScript puro, com:

- cena 3D da picape no topo (Three.js, em `js/frete3d.js`)
- animações de rolagem com GSAP e ScrollTrigger
- efeitos de computador (cursor, botões magnéticos, fotos em 3D) em `js/efeitos-premium.js`
- formulário de orçamento rápido que abre o WhatsApp com a mensagem pronta

As bibliotecas ficam em `js/libs`, então o site funciona sem CDN.
